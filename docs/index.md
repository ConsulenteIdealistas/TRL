# 学術・技術ダイジェスト

> 本ダイジェストは公開情報の整理であり、投資助言ではありません。

## 最新
- `YYYY-MM-DD-input.md`（AI 入力ファイル）
- `YYYY-MM-DD.md`（評価済みダイジェスト。自動評価成功時は自動生成）

## 使い方
1. `-input.md` を開いてコピー（手動評価する場合）
2. Claude/ChatGPT に貼り付けて評価
3. 出力を Issue に貼り付け（テンプレート `ai-eval-result`）
4. 数分後に `YYYY-MM-DD.md` が生成されます

自動評価（Gemini）が有効な日は、`YYYY-MM-DD.md` が最初から存在します。
