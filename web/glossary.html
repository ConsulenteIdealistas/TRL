用語集

このサイトで使う言葉の定義です。採点の詳しい規則は採点基準にあります。定義が変わるときは規程の版と一緒に変わります。

評価の軸

TRL（技術成熟度レベル）
技術が実証された成熟度を 1〜9 で表す段階です。項目「技術成熟度」の点から決まります。商用の進み具合は測りません（売上や展開は事業側の項目で見ます）。証拠が無いときは「未確定」で、低い段階とは別です。
総合点
6項目の加重合計（0〜100）。重みは技術成熟度30 / 技術的優位性15 / 収益化能力20 / 市場成長性15 / 財務的持続可能性10 / 競争優位性の持続性10 です。
帯域
総合点の区間表示です。0–19 極めて弱い / 20–39 弱い / 40–59 中程度・不確実 / 60–79 強い / 80–100 非常に強い。
参考項目（経営陣・実行力）
併記するだけの項目で、総合点にも必須判定にも入れません。
null（未確定）
証拠が資料に無い項目には点が付きません。0点（できていない）とは意味が違うため、不足として数え、材料の補強対象になります。
方向性
資料が示す出来事の追い風・逆風を、点数とは独立に判定したもの。ポジティブ / ネガティブ / 混在。出来事が無いときは未判定です。

候補の状態

選定可能（final）
必須項目がそろい、評価が確定した候補です。
保留（hold）
評価は行われたが確定できない候補です。理由は「企業を特定できず」（資料の中で対象企業を一意に定められなかった）か「根拠不足」（必須項目の根拠が資料に無かった）のいずれかです。
要追加調査（review）
監査で要確認が付き、人の処分を待っている候補です。
未評価（pending）／除外（rejected）
未評価はまだ long 評価を受けていない候補、除外は対象外と判定された候補です。
次回評価予定
選定の順序で次回の実行に入る候補です。再評価の予約とは別です。

企業と市場

層（ティア）
企業単位の区分で Core / Conditional / Look / See の4層です。目標比率は 2:3:4:1。Core は評価が確定し企業リンクが一意で未処分の要確認が無い企業、Conditional はその条件のいずれかが未充足の評価対象、Look・See は評価対象外の監視企業です。
関門（barriers）
一次情報の証拠条件から機械的に判定する表示専用の目印で、採点や選定には使いません。Devil River＝TRL 3以下で治験の Phase 1 以上が始まっていない、Valley of Death＝TRL 4以上で資金の持ち（ランウェイ）が1年未満、Darwinian Sea＝TRL 7以上で通期売上が前年より減った状態です。判定材料が足りないときは「判定しない」になります。
段階（ステージ）
企業の事業段階の表示で、研究開発型 / 実証型 / 量産型 / 商業化型。表示・分析専用で、採点の入力には使いません。
付記（annex）
ARL（提携・販売などの到達）/ IRL（統合）/ SRL（社会実装）の観測イベントを詳細画面に記録する仕組みです。スコア・選定・層・監査には触りません。

運用と監査

世代
規程とプロンプトの版の組み合わせです。旧世代の評価は現在の物差しと混ぜず、世代表示の切り替えで分けて見られます。
監査
評価の後に決定的な規則（A・E・P の各規則と API 照合）で照合する仕組みです。引っかかったものは「要確認」として残り、人の処分（確定・再評価など）で閉じます。LLM は監査に使いません。
母集団（コホート）
統計の対象集合です。既定は表示時点で選定可能な候補の最新の評価で、カレンダーで基準日を選ぶと、その日時点の集合に固定されます。
統計量
四分位数は線形補間（type 7）、標準偏差は標本標準偏差（n−1）です。Sn と Qn は Rousseeuw & Croux のロバストなばらつきの推定量で、外れ値に引かれにくいのが特徴です。実装は R の robustbase と照合済みです。
一次情報／監視材料
一次情報は企業自身の開示（決算・適時開示・治験登録など）で、監視材料は Look・See の企業について集めている材料です。
