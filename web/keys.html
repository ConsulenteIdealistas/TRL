キー操作の説明書

キーボードだけで一覧を読み進め、絞り込み、BANし、ページを渡り歩くための全操作です。色の付いたキーが使えるキーで、色は役割ごとに分かれています。キーを押す[タップする]と、そのキーの説明に印が付きます。右上に紫の丸があるキーは、g の後に押すページ移動[g シーケンス]でも使います。キーの下に橙色で書いた「Shift:」は、Shift を足したときの働きです。? は Shift+/ のことで、図では / と同じキーに2段で入っています。

コマンドとキー操作の違い

「コマンド」はこのサイトでできる操作の全体です。コマンドパレット[Ctrl+K]に全て入っていて、名前で検索してそのまま実行できます。「キー操作」は、そのうちキーボードのキーに割り当てたものの呼び方です。? のキー操作一覧には全コマンドが載っていて、キーの付いたものが先、キーなし[パレット専用]のものが後に並びます。キーなしの操作が「無い」のではなく、キーで呼べないだけです。

移動・選択

j / k次の候補 / 前の候補へ移動します。一覧の並び順どおりに選択が移ります。
Enter選択中の候補の詳細ページを開きます。複数選択モード中は、詳細でなく選択の切り替えになります。
k前の候補へ[j の逆]。g の後に押すとこの説明書を開きます。
Shift+J / Shift+K10件 次 / 前の候補へ移動します。
p / Shift+P選択中の候補と同じ企業[最初の strong リンク]の候補だけを 次 / 前へ巡回します。何件目かは通知に出ます。
Shift+N未読の候補[詳細をまだ開いていない候補]だけを次へ巡回します。何件目かは通知に出ます。末尾まで行くと先頭に戻ります。
u / Shift+U前回から「動いた」候補[TRLか総合点が変わった・帯域を跨いだ・方向性が反転した]だけを 次 / 前へ巡回します。何件目かは通知に出ます。末尾まで行くと先頭に戻ります。

絞り込み・検索

1〜9 / 0TRLチップを直接切り替えます。0 は「未確定」。BAN中のTRLは切り替えできず、通知が出ます。
/検索欄へ移動します。検索欄では ↑↓ で候補を選び Enter で確定します。src: のような記法を打ち始めると、その演算子で使える値が補完候補に出ます。
s並び順を次へ切り替えます。
, / .並び順を前へ / 次へ切り替えます[s は次へだけ]。
n「新着だけ表示」を切り替えます。

候補への操作

f選択中の候補をピン留め / 解除します[この端末に保存]。
c比較バスケットに追加 / 解除します[最大4件]。帯から横並び比較ページを開けます。
v複数選択モードの入 / 切。モード中はカードのクリックが選択の切り替えになり、画面下のバーから一括ピン・バスケット追加・企業BANができます。
w / Shift+W「あとで読む」に追加 / 解除。Shift+W は、あとで読むの帯へ移動します。
e / Shift+Ee は原文を新しいタブで開き、Shift+E は根拠[関連材料の先頭]を開きます。
m詳細の調査メモ欄へ移動します。
n新着だけ表示の切り替え[絞り込みの節も参照]。
r選択中の候補の再評価を予約 / 解除します[監査ページの予約と同じ記録で、カードに青い「予約」バッジが付きます]。予約は反映用JSON経由でDBに届きます。解除はこの端末だけに効きます[DBの予約行は追記専用のため]。
y選択中の候補の詳細ページへのリンクをコピーします。

BAN[除外]

b / Shift+B選択中の候補の企業 / 市場をBAN切り替えします。BANした瞬間、スマホでは軽く振動します。
チップの長押し / 右クリックどの絞り込みチップでも、長押し[スマホ]または右クリック[PC]でその値をBANできます。もう一度で解除。BAN中のチップは通常のクリックでは操作できません[解除は長押し/右クリックだけ]。条件リセットでBANも全て解除されます。
BANの復元企業・市場をBANすると候補はその場で消えますが、復元の入口は3つあります: (1) BANした直後の通知にある「戻す」[キー操作のときだけ出ます]、(2) 一覧の上に出る「BAN中の企業・市場」の帯の×[いつでも押せます。「全部戻す」もあります]、(3) 詳細・出力のBANパネルのスイッチと×。詳細ページで付けた企業BANも、帯とパネルに出ます。
BANチップ[モード]各チップ群の末尾にある「BAN」と書かれたチップです。押すと赤く光り、その群がBANモードになります。光っている間は、チップのタップが選択でなくBANの切り替えになるので、スマホでも長押しなしで素早くBANできます。もう一度押すと通常モードに戻ります。モードは保存されず、開き直すと通常モードです。
Cmd+X[全BAN]BANチップが光っている群があるときだけ効きます。対象は最後に光らせた群だけです[複数光っていても同時に効かせないための仕組み]。その群の値を全部BANし、効いた群はモードを抜けます。既に全部BANなら全部解除します[同じキーで行き来できます]。入力欄にいる間は本来の切り取りが優先されます。
BANパネル企業・分野・出所は名前で指名してBANできます。BAN一式はJSONで書き出し/読み込みができ、条件と束ねた「プロファイル」としても保存できます。

表示

d世代表示[旧世代の評価をどう扱うか]を切り替えます。
l表示言語[日本語訳 / 原文]を切り替えます。
;コンパクト表示を切り替えます。
a条件をリセットします[BANも含めて全解除]。

ページ移動[g シーケンス]

g の後に1キーg を押してから0.9秒以内に次のキーを押すと、そのページへ移動します。全ページ共通です。
g i / a / c / w / o / b / q / r / d / l / kメイン / 監査 / 採点基準 / Look・See / 観測 / ブリーフィング / 次回評価予定 / 実行履歴 / 項目別の不足 / 用語集 / この説明書、の順です。

観測ページ専用

[ / ]基準日[as-of]を評価日の単位で前 / 次へ送ります。最後より先へ送ると「最新」に戻ります。
← / →統計[箱ひげ図]の項目ハイライトを巡回します。

詳細ページ専用

j / k前後の候補の詳細へ移動します。並びは data.json の候補の並び順です[一覧の絞り込み・並び替えは持ち込みません]。
fこの候補をピン留め / 解除します[一覧の注目と同じ保存先]。
bこの候補の企業[最初の strong リンク]を BAN / 解除します[一覧の企業BANと同じ保存先]。
rこの候補の再評価を予約 / 解除します[監査ページ・一覧と同じ記録]。
yこの詳細ページのリンクをコピーします。
e原文サイトを新しいタブで開きます。

監査ページ専用

?監査ページのキー操作の一覧を開きます[一覧ページの ? と同じ流儀で、全コマンドが載ります]。
j / k監査の項目[エントリ]を 次 / 前へ移動します。候補ではなく項目単位です。
1 / 2 / 3選択中の項目に処分を付けます: 1=問題あり、2=誤検知、3=様子見。その項目のチップを押すのと同じで、もう一度押すと取り消します。処分した項目が未処分リストから外れると、選択は次の項目に移ります。
r選択中の項目の候補について、再評価を予約 / 解除します[長期評価のカードだけ]。
Enter選択中の項目の候補の詳細ページを開きます。

画面・その他

Shift+D / Shift+L / Shift+Cテーマを ダーク / ライト / 色覚配慮 に切り替えます [この端末に保存、全ページに効きます]。上の「テーマ」ボタンでも順に切り替わります。Ctrl+系にしなかったのは、Ctrl+L がブラウザのアドレスバーに取られてページに届かないためです。
Ctrl+K[Mac は Cmd+K]コマンドパレットを開きます。全コマンドを名前で検索して実行できます。書き出しやページ移動もここからできます。
?キー操作の一覧[簡易版]を開きます。一覧の中は言葉で検索できます。「キー操作の練習」ボタンで、実際にキーを押す練習もできます。? は Shift+/ で、キーボードでは / と同じキーです[図でも同じキーに入っています]。
Escパレットやキー一覧を閉じます。何も開いていないときは、光っているBANモードを全部抜けます。
Shift+S滑らかスクロールの入 / 切を切り替えます[この端末に保存、全ページ共通]。入のときは、マウスホイールの刻みを、氷の上を滑るような摩擦モデル[残りの距離に比例した速度で近づく指数減衰]でつないで滑らかにスクロールします。指のノイズ補正として、刻みの大きさをそのホイールの標準ノッチに丸め、滑走中の単発の逆向きは保留し、微小な入力は貯めてから反映します。トラックパッドの細かいスクロール、内側のスクロール領域、Ctrl+ホイール[ズーム]には触りません。

効かないとき

検索欄などの入力欄にフォーカスがある間と、日本語入力の変換中は、キー操作は効きません[入力を邪魔しないため]。入力欄から離れるには Esc を押すか、欄の外をタップしてください。この説明書は g の後に k、またはキー一覧[?]からのリンクでも開けます。
