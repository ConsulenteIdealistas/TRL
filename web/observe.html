観測

評価そのものではなく、「評価の集まりがどう動いているか」「収集が健全に回っているか」を眺めるページです。一覧は候補を見る場所に専念させ、分布・統計・実行の観測はこちらに集めました。数字はすべて data.json の輸出値からの決定的な集計で、画面側で新しい判定はしていません。

なぜ統計を取るのか

このサイトの目的は、TRL（技術成熟度）の上昇と下降を観測することです。1社の点だけを見ていても、それが「いつもと違う動き」なのか「全体の流れ」なのかは分かりません。統計は、そのための計器盤です。使い道は4つあります。

1. 1社の点を、集まりの中の位置として読むため
「総合60点」が高いのか普通なのかは、母集団の分布が決めます。中央値が59の集まりでの60点と、中央値が40の集まりでの60点では意味が違います。個別の評価は、分布と並べて初めて解釈できます。
2. 評価プロセス自体の異常を見つけるため
特定の項目だけ未確定（null）が多い、散らばりが急に広がった、といった変化は、候補の変化ではなく「材料が集まっていない」「評価が不安定」というプロセス側の異常のことがあります。統計はその検出器です。
3. 材料の補強先を決めるため
null の多い項目は、証拠が集まっていない項目です。どの項目・どの分野が弱いかが見えれば、収集の補強（材料を増やす手当て）を感覚ではなく件数で優先順位付けできます。
4. 物差しの変更の影響を測るため
採点の規程や重みを変えたとき、点の水準がどれだけ動いたかは世代別の中央値の比較で測れます。「候補が変わったから動いた」のか「物差しが変わったから動いた」のかを切り分けるのが、世代別と基準日（as-of）の役割です。

逆に、統計は投資の判断そのものではありません。点の集まりの眺めは観測と手当てのためのもので、「平均が高いから買い」のような読み方はしません。

統計（確定評価の母集団）

なぜ平均だけでなく中央値と箱ひげ図を載せるのか。評価点には極端に高い・低い候補が混ざります。平均はその数件に引っ張られて動きますが、中央値は「真ん中の候補」そのものなので典型像がぶれません。箱ひげ図は、中央値に加えて「真ん中50%の幅（箱）」と「全体の幅（ひげ）」を一度に見せる図で、点が揃っているのか散っているのかが読み取れます。詳しい読み方は末尾の「統計の読み方」にあります。

分布と散布図

総合点とTRLの度数（棒）、再評価でどれだけ動いたか（散布図）、項目ごとの未確定（null）の件数です。分布の形が変わっていくこと自体が、観測の対象です。

直近の動き

あと1項目で確定

保留のうち、必須項目の不足があと1項目だけの候補です。「材料の補強先を決める」ための最優先リストで、不足項目が見えているので、どの材料を集めれば確定に届くかがそのまま分かります。

翻訳使用量

翻訳は無料枠の文字数で回しています。上限に近づいたら気づけるよう、使用量をここに常設します。

収集と実行

収集の成功率とソース別の失敗率です。失敗が増えたソースは、材料の偏り（＝評価の偏り）に直結するので監視します。実行ごとの詳細は実行履歴ページにあります。

統計の読み方

母集団
統計の対象は「選定可能（final）」の候補の最新の long 評価だけです。保留はまだ点が確定していないので混ぜません（混ぜると、統計が「候補の姿」と「未確定の多さ」の二重の意味になってしまうため）。
平均と中央値
平均は全員の真ん中、中央値は順位の真ん中です。両方が大きく離れているときは、少数の極端な候補が平均を引っ張っています。その場合は中央値が典型像です。
箱ひげ図
箱の左端が Q1（下から25%の点）、右端が Q3（75%の点）、箱の中の線が中央値、ひげの両端が最小と最大です。箱が狭い＝評価が揃っている、箱が広い・ひげが長い＝ばらつきが大きい、と読みます。目盛りは 0・25・50・75・100 で、最小・Q1・中央値・Q3・最大の数が図の上に並びます。低域に点が固まって潰れるときは、統計の上の「目盛り」ボタンで対数表示に切り替えられます（log(1+x) で伸ばし、目盛りは元の値で読みます）。対数で数字が重なる項目では、図のラベルを一部省きます（数字の行に全値があります）。
SD と Sn・Qn（散らばりの物差しが3つある理由）
SD（標準偏差）はよく知られた散らばりの物差しですが、外れ値に弱く、極端な1件で大きく膨らみます。Sn と Qn は外れ値に強い（ロバストな）散らばりの物差しです。SD だけが大きくて Sn・Qn が小さいときは、「散らばりは外れ値のせいで、本体は固まっている」と読めます。逆に全部大きいときは、本当に散っています。点が数段の決まった値に固まる項目（例: 市場成長性）では Qn が 0 になることもあります。
世代別
採点の物差し（規程と重みの版）が違う評価を混ぜて中央値を出すと、変化が「候補の変化」なのか「物差しの変化」なのか区別できません。だから世代（config の版）ごとに分けて出しています。
基準日（as-of）
カレンダーで日を選ぶと、その日時点の母集団（各候補の、その日以前で最新の評価）で統計を再構成します。「当時はどう見えていたか」を、後から増えた評価で塗り替えないための仕組みです。
一般的な背景（外部の参考）
定義と計算方法は上記のとおり、このサイトの決めが正本です。一般的な統計用語の背景は Wikipedia「箱ひげ図」「中央値」「四分位範囲」「標準偏差」「外れ値」「対数」も参照できます。
