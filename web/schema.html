データ形式の変更履歴

サイトが読む data.json の形式 (schema) の履歴です。現行は schema_version = 3 です。キーの追加だけでは版を上げない方針で、Web が読むキーの契約は web/schema.json にあります。

2026-11-24

digest / next_queue を追加
最新ランの全評価（前回値つき）と、次回の選定順の候補 ID 列です。変化ダイジェストと次回キューの表示に使います。
candidates[].history を追加
long 評価が2件以上ある候補に、古い順の軽い点列（evaluated_at / status / total / band / trl_level / gen_config / items / direction）を持ちます。統計の基準日 (as-of) 再構成と評価の推移の材料です。
run_history / source_stats を追加
終了ランの要約（古い順、直近30件）と、基準ランのソース別収集量です。source_stat には後に top_errors（失敗理由の上位3件）も追加しました。
related_financials[].source を追加
関連財務根拠の出所（収集ソース）を同梱します。財務補間の適用状況の表示に使います。
feed.xml の生成を開始
最新ランの評価を Atom フィードとして書き出します（data.json の追加キーではありません）。

2026-11-22

translation_usage を追加
翻訳の月次・累計の文字数（Azure / Google / DeepL）です。使用量のゲージとしきい値監視に使います。Web の契約 (schema.json) には載せない監視専用のキーです。
